# Руководство пользователя SalesAgent AI

Это руководство предназначено для владельца бизнеса или администратора, который впервые видит панель. После чтения вы сможете зарегистрировать организацию, подготовить знания, создать своего агента и провести текстовый и голосовой тест.

## 1. Что нужно заранее

Для входа и просмотра интерфейса достаточно работающего сервера и MySQL. Для полноценного теста нужны:

- OpenRouter API key и/или Cerebras API keys — агент формирует ответы; OpenRouter также используется для embeddings;
- Cartesia API key — быстрый потоковый синтез Sonic 3.5; рекомендуется для звонка;
- Fish Audio API key — резервный или альтернативный синтез речи;
- voice ID — идентификатор выбранного голоса Cartesia или Fish Audio, но не API-ключ;
- HTTPS — нужен для безопасной production-работы, микрофона и Voximplant;
- Voximplant — только для настоящего телефонного номера;
- Redis — для постоянных фоновых очередей;
- S3 — для хранения записей.

Откройте после входа раздел «Справка и настройка». Блок «Готовность интеграций» показывает только состояние, но никогда не раскрывает секреты.

## 2. Регистрация

На странице регистрации заполните:

| Поле | Значение |
|---|---|
| Название организации | Компания или отдельный проект |
| Ваше имя | Имя первого администратора |
| Email | Уникальный логин |
| Пароль | Не менее 8 символов; используйте уникальный пароль |

Регистрация создаёт организацию, администратора, пробную подписку и стартового голосового агента Mommy. Его можно сразу выбрать в тесте звонка или изменить в разделе «Агенты».

## 3. Настройка сервера

Секреты задаются в окружении, а не в карточке агента.

| Переменная | Что означает |
|---|---|
| `MYSQL_URL` | MySQL/MariaDB, где хранится вся рабочая информация |
| `JWT_SECRET` | Секрет подписи сессий, минимум 32 символа |
| `OPENROUTER_API_KEY` | Секретный ключ OpenRouter |
| `OPENROUTER_DEFAULT_MODEL` | Модель по умолчанию |
| `CEREBRAS_API_KEYS` | Ключи Cerebras через запятую для распределения квоты |
| `CEREBRAS_DEFAULT_MODEL` | Cerebras fallback, обычно `gemma-4-31b` |
| `CEREBRAS_FALLBACK_OPENROUTER_MODEL` | OpenRouter fallback после исчерпания Cerebras |
| `VOICE_FAST_MODEL` | Быстрый голосовой контур, по умолчанию `cerebras/gemma-4-31b` |
| `VOICE_DEEP_MODEL` | Фоновый анализ сложных вопросов, `deepseek/deepseek-v4-pro` |
| `VOICE_DEEP_MAX_TOKENS` | Бюджет глубокого рассуждения, по умолчанию `2400` |
| `VOICE_DEEP_TIMEOUT_MS` | Таймаут фонового запроса; быстрый диалог при этом не блокируется |
| `CARTESIA_API_KEY` | Секретный ключ Cartesia для быстрого потокового TTS |
| `CARTESIA_MODEL` | Модель Cartesia, по умолчанию `sonic-3.5` |
| `CARTESIA_DEFAULT_VOICE_ID` | Русский голос Cartesia по умолчанию |
| `FISH_AUDIO_API_KEY` | Секретный ключ Fish Audio |
| `FISH_AUDIO_DEFAULT_VOICE_ID` | Необязательный голос Fish Audio по умолчанию |
| `VOICE_WEBHOOK_SECRET` | Отдельный секрет для Voximplant |
| `PUBLIC_BASE_URL` | Публичный HTTPS-адрес |
| `REDIS_URL` | Redis или `memory` для первичной проверки |
| `WAZZUP24_API_KEY` | Доступ WhatsApp-провайдера |
| `WAZZUP24_CHANNEL_ID` | Канал Wazzup24 |
| `WAZZUP24_WEBHOOK_SECRET` | Проверка входящих Wazzup24 webhook |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram Bot |
| `TELEGRAM_WEBHOOK_SECRET` | Проверка Telegram webhook |
| `VOXIMPLANT_ACCOUNT_ID` | Аккаунт телефонии |
| `VOXIMPLANT_API_KEY` | Ключ телефонии |
| `S3_ENDPOINT` | Адрес хранилища записей |
| `S3_ACCESS_KEY` | Логин S3 |
| `S3_SECRET_KEY` | Секрет S3 |

API-ключ Cartesia или Fish Audio нельзя вставлять в поле voice ID. API-ключ даёт серверу доступ к сервису; voice ID выбирает конкретный голос.

## 4. База знаний

Сначала загрузите информацию, на которую должен опираться агент:

- товары и услуги;
- цены;
- доставка и сроки;
- гарантии и возвраты;
- FAQ;
- скрипты обработки возражений.

Поддерживаются PDF, CSV, TXT и Markdown до лимита интерфейса.

Поле «Категория»:

| Значение | Когда использовать |
|---|---|
| Общее | О компании и смешанные сведения |
| Товары | Каталог и характеристики |
| Цены | Прайсы и тарифы |
| Доставка | География, сроки и стоимость |
| FAQ | Частые вопросы |

После загрузки выполните «Тест поиска». Введите вопрос словами реального клиента. Если правильного фрагмента нет среди первых результатов, разбейте документ на более понятные темы или уберите противоречия.

«Фрагментов» показывает, на сколько частей разбит файл. Удаление файла удаляет все его фрагменты.

## 5. Создание агента

Откройте «Агенты» и нажмите «Новый».

| Поле | Как настроить |
|---|---|
| Имя агента | Имя продавца, которое увидит администратор |
| AI-провайдер и модель | Выберите Cerebras → Gemma 4 31B для быстрого голоса или любую модель OpenRouter; точный ID можно ввести вручную |
| TTS-провайдер и голос | Для минимальной задержки выберите Cartesia Sonic 3.5 и русский голос из каталога; Fish Audio доступен как альтернатива и автоматический резерв |
| Каналы | Включите нужные WhatsApp, Telegram и обязательно `voice` для звонка |
| Температура | `0.6–0.8` для продаж; ниже — строже, выше — вариативнее |
| Макс. токенов | `256–700` для короткой речи, `700–1500` для подробного чата |
| Системный промпт | Роль, тон, ограничения и правила использования инструментов |

Рекомендуемый первый промпт:

```text
Ты — менеджер по продажам компании [название].
Отвечай кратко и по-русски.
Перед ответом о товарах, ценах и доставке используй search_knowledge.
Не выдумывай факты. Если данных нет, задай уточняющий вопрос.
Когда клиент готов продолжить, зафиксируй этап лида.
```

Храните факты и цены в базе знаний, а поведение и стиль — в промпте.

Кнопка удаления деактивирует агента. История не стирается.

## 6. Текстовый тест

Откройте «Чат с агентом»:

1. выберите активного агента;
2. спросите о товаре или услуге;
3. спросите цену и доставку;
4. сформулируйте возражение;
5. попросите записать на консультацию.

Проверьте:

- нет ли выдуманных фактов;
- используется ли информация из документа;
- подходит ли тон;
- достаточно ли короткий ответ;
- появились ли tool calls в журнале разговора.

«Новый разговор» создаёт новую браузерную сессию.

## 7. Голосовой тест

Откройте «Тест звонка»:

1. убедитесь, что OpenRouter STT, Cerebras или OpenRouter LLM, а также Cartesia или Fish Audio готовы;
2. выберите активного агента с каналом `voice`;
3. разрешите доступ и выберите конкретный микрофон и аудиовыход;
4. нажмите зелёную трубку;
5. говорите без дополнительных кнопок: запись сама завершится после паузы, ответ прозвучит и микрофон включится снова;
6. кнопка микрофона только выключает или включает передачу звука;
7. задайте простой вопрос и проверьте быстрый ответ Gemma 4;
8. задайте сложный вопрос с анализом, сравнением или расчётом: Gemma продолжит разговор, пока DeepSeek V4 Pro готовит вывод в фоне;
9. актуальный глубокий ответ прозвучит автоматически в ближайшую паузу;
10. если после исходного вопроса уже появилась новая реплика, DeepSeek не перебьёт тему: используйте «Озвучить» или «Скрыть» в карточке глубокого контура;
10. завершите звонок красной трубкой и проверьте историю.

Браузер сохраняет выбранный `MediaStream` открытым между репликами, backend отправляет законченную реплику в OpenRouter `audio/transcriptions` с моделью `deepgram/nova-3`, а Gemma 4 на Cerebras формирует короткий основной ответ. Cartesia Sonic 3.5 отдаёт MP3 по мере получения от API, поэтому браузер может начать воспроизведение до полной загрузки файла; Fish Audio остаётся альтернативой и автоматическим резервом. Локальный классификатор без сетевой задержки отправляет сложные вопросы в DeepSeek V4 Pro; результат хранится в MySQL и не блокирует основной разговор. Результат привязан к исходной реплике и не произносится автоматически после смены темы. Это автоматический turn-based тест без телефонного номера, а не одновременный full-duplex.

На обычном HTTP браузер может запретить микрофон. Для браузерного теста нужен HTTPS, для звонка на телефонный номер дополнительно нужен Voximplant.

## 8. Каждый раздел панели

### Дашборд

- «Лиды» — уникальные клиенты.
- «Разговоры» — отдельные сессии.
- «Конверсия» — доля успешных закрытий.
- «Ср. ответ» — задержка ответа агента.
- Воронка — распределение лидов по этапам.
- Разговоры по дням — динамика активности.
- План — расход лимита сообщений.

### Чат с агентом

Выбирает любого активного агента и использует общий RAG/tool pipeline. Ошибка до первой реплики обычно означает отсутствие ключей выбранного AI-провайдера или неправильный model ID.

### Разговоры

- Канал — WhatsApp, Telegram, voice или внутренний chat.
- Этап — состояние лида.
- Статус — состояние сессии.
- Сообщ. — количество реплик.
- Время — начало разговора.

Нажмите строку, чтобы открыть сообщения, инструменты, задержки и запись.

### Записи

Содержит аудио, транскрипты, маркеры и оценку разговора. Пустой список нормален до подключения телефонии и S3.

### База знаний

Управляет источниками RAG и позволяет увидеть реальные результаты поиска до запуска агента.

### Агенты

Создаёт и редактирует продавцов. Агент должен быть активен и иметь нужный канал.

### Тест звонка

Проверяет голос без внешней телефонии. Для production-звонка нужен защищённый публичный webhook.

### Справка и настройка

Показывает готовность сервера, полный путь настройки, поля, адреса webhook и диагностику.

### Тема

Кнопка в нижней части бокового меню переключает светлую и тёмную тему. Выбор хранится в браузере. До входа кнопка находится в правом верхнем углу.

### Выйти

Удаляет защищённую HttpOnly-сессию и локальный ID организации. Данные организации в MySQL не удаляются.

## 9. Внешние каналы

WhatsApp webhook имеет вид:

```text
https://ваш-домен/api/webhooks/whatsapp/ORG_ID
```

Telegram webhook:

```text
https://ваш-домен/api/webhooks/telegram/ORG_ID
```

Voximplant отправляет turns на:

```text
https://ваш-домен/api/voice
```

Все внешние каналы должны передавать настроенные секреты. `ORG_ID` показывается во встроенной справке.

## 10. Частые ошибки

| Ошибка | Что сделать |
|---|---|
| Белый экран | `Ctrl+Shift+R`, затем проверить `/health` |
| Ни один AI-провайдер не готов | Добавить `OPENROUTER_API_KEY` или `CEREBRAS_API_KEYS` и перезапустить процесс |
| Агент не отвечает | Проверить key, model ID и квоту |
| Нет голоса | Проверить ключ выбранного Cartesia/Fish Audio, voice ID и квоту; при наличии второго провайдера backend использует его как резерв |
| Нет агента в voice test | Активировать агента и канал `voice` |
| Микрофон не работает | Разрешить доступ или использовать ручной ввод |
| Поиск пустой | Загрузить документ и проверить embeddings |
| Webhook `401` | Исправить секрет |
| Webhook `503` | Задать соответствующий секрет в окружении |
| Voice `426` | Подключить HTTPS |

## 11. Безопасность

- Не публикуйте `.env`.
- Не отправляйте API-ключи в поле voice ID или model ID.
- Не используйте на HTTP пароль от другого сервиса.
- Для production подключите HTTPS.
- Не отключайте проверку voice webhook на постоянной основе.
- После изменения окружения перезапустите процесс.
