# Переиндексация RAG embeddings

Миграция `005_embedding_model.sql` помечает модель каждого вектора и
обнуляет старые немаркированные embeddings. Это временно исключает их из
поиска и не даёт сравнивать векторы разных моделей.

После применения миграций запустите:

```bash
npm run build
npm run rag:reindex
```

Команда читает `DATABASE_URL`, `GOOGLE_API_KEY` и
`GEMINI_EMBED_MODEL=gemini-embedding-2` из окружения. Она обрабатывает все
пропущенные или несовместимые чанки. Повторный запуск безопасен и не
обращается к API, если все векторы уже актуальны. Одновременно может
работать только один экземпляр команды.
В production/Docker команда запускает скомпилированный
`dist/rag/reindex-cli.js` и не требует dev-зависимостей.

```bash
docker compose run --rm app npm run rag:reindex
```

Вывод содержит только количество чанков и пакетов; тексты чанков и ключи
не печатаются. Переиндексация использует квоту Google Embeddings; на большой
базе сначала проверьте лимиты и баланс аккаунта.
